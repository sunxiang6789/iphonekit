# 操作手机时的规则（通过 iphone-use）

> 这份规则给 Claude Code / Codex 在你直接和它对话时用（写进 `~/.claude/CLAUDE.md` 或 `~/.codex/AGENTS.md`）。
> 通过快捷指令下命令走的是桥接服务，用的是 `rules.md`，和这份互不影响。
> 安装向导会把这份规则放进一个「标记块」里，升级时只替换标记块，不动你自己写的其他内容。

- 通过 iphone-use 操作手机时，任何付款、转账、购买、充值，以及其他需要我本人确认的操作，最后一步由我自己来：做到付款/确认页面就停下，不要点最后的确认或支付按钮，按下面「停在付款/确认页」收尾，由我自己在手机上付款或确认。
- 不删除数据（照片、消息、文件、购物车里原有的东西），除非我明确说了要删什么。

## 开始前的准备

1. **先读个人档案** `~/.config/iphone-agent-kit/profile.md`，做选择时（口味、地址、预算、用哪个 App）按档案来。档案里有的不要再问我。
2. 档案里没有、又必须知道的信息，开始前只问我一句，我答完就记进档案，下次不再问。其余没说清的细节按档案和常识选，不要追问。
3. 手机现在不可操作（交还状态、runner 没起来）而我要你用手机时，**直接**重新接管并等到可以操作，不要先问我。只有状态显示手机锁屏或要输入密码（`locked`、`needs_passcode_on_phone`）才来问我。启动后只等一次（用一条命令轮询到 `drivable=true`），不要反复查状态。
4. **先回主屏幕**再开始，避免前台是内容很长的页面，屏幕读取超时。
5. 打开任何 App 前，**必须**先用 `phone_apps`（`source: installed`）按已安装列表查包名，再用包名启动，不要凭名字猜。

## 个人档案的更新

每个手机任务做完后，对照这一轮出现的新信息检查档案有没有要补或要改的：我临时选的口味、我纠正你的地方、我说的新地址或新习惯等。
- 有就**直接写进档案，不用先问我**，并在聊天里告诉我记了什么。
- 和旧内容冲突的（比如我换了地址），**覆盖**旧的那一行，更新日期，不要留着旧的、也不要追加重复的。
- 永远不记：密码、支付密码、银行卡号、身份证号、验证码，我告诉你也不要写进档案。
- 档案里的地址等个人信息只用来做决定，不要放进推送内容里。

## 简单任务要快

查信息、发消息、打开 App、设闹钟这类简单的手机任务，做事要快（我在等你）：
- 不要先说你打算做什么，直接动手。
- 先读一次屏幕，把看得到怎么做的步骤一次批量做完，不要一步一步试探。
- 拿到我要的结果就马上收尾，不要多余的检查和确认。
- 不用碰手机就能回答的（比如聊天），直接回，别操作手机。

要挑选、比价、规划、花钱的任务不受这一段限制，该比较就比较。收尾照样按下面「任务的两种结束方式」做。

## 任务的两种结束方式

**1. 任务结束停止**（办成、办不成都算；停在付款/确认页见下面的例外）：
1. 回到主屏幕（按 Home 键），确认已在主屏幕。
2. **必须**立即关掉 runner（不是只交还控制权）：先调用 `phone_release_owner`，再运行 `sh ~/.config/iphone-agent-kit/stop_runner.sh`，返回里看到 `"ok":true` 才算关掉。不要自己拼 curl（8787 是手机上的服务，Mac 上的在 44321 而且要密码，脚本里都写好了），不要等待空闲自动释放。原因：不关的话手机会一直处在自动化状态，我拿起来用会被打扰。
3. 用 Bark 推送一句话给我（格式见下面「推送」）。

例外 · **停在付款/确认页**：需要我本人付款或确认时（包括刷脸、输支付密码），停在这一页就是任务的终点：
1. 留在当前页面，**不回主屏幕**（我在任务里明确要求回主屏幕的除外）。
2. 用 Bark 推送告诉我付给谁、多少钱（或要我确认什么），让我自己去手机上付。
3. 照样关掉 runner：先 `phone_release_owner`，再运行 `sh ~/.config/iphone-agent-kit/stop_runner.sh`，看到 `"ok":true` 才算关掉。
我付完或确认完不用你再收尾。

**2. 用户停止**（发现我在用手机）：
**必须**立即暂停任务，不回主屏幕、不再点任何东西，然后：（原因：继续点会跟我抢着操作手机，可能点错东西。）
1. 用 Bark 推送一句话，意思是「你先用手机，用完可以找我继续任务」。
2. 关掉 runner：先 `phone_release_owner`，再运行 `sh ~/.config/iphone-agent-kit/stop_runner.sh`（如果我已经手动关了 runner，就不用再关）。
3. 在聊天里说清楚任务做到哪一步、还差什么，方便我回来让你接着做。

怎么判断我在用手机，有两种：
- **我手动关了 runner**：phone_status 里出现 `human_handoff: true` / `mode` 为 human，或操作被拒绝、返回 `phone_handed_to_human`。这时绝对不要 phone_reconnect 把手机抢回来。
- **我在操控屏幕**：只能靠观察屏幕变化识别。每一步操作后读到的屏幕，如果出现不是你的操作造成的变化（前台 App 换了、页面跳到别处、输入框里多了你没输入的文字、列表滚到了别的位置等），就当作我在用手机。偶尔的弹窗、通知横幅、广告、页面自己刷新不算；拿不准时再读一次屏幕，确认变化还在、而且不是你造成的，才判定为我在用。

## 推送

`python3 ~/.config/iphone-agent-kit/bark_push.py "推送内容"`

推送内容只写一两句、十几个字，只说我最想知道的结果，不要汇报腔、不提技术细节。例：「还剩200多G，放心用」「消息发出去了」「手机锁住了，需要你解锁」「要付21块给美团，可以吗？」「你先用手机，用完再找我继续」。这条规则只管推送内容，聊天回复照常。
