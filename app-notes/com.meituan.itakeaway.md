# 美团外卖操作笔记（社区笔记）

> 记录环境：iPhone 17 Pro / iOS 27 / 2026-10。坐标是屏幕比例的**约值**，App 改版或换机型后可能不准，以截图为准。
> 通过 iphone-use 的 `PUT /agent/app-notes?bundle=com.meituan.itakeaway` 写入（安装向导可代劳）。

- 控件树经常是空的（只读到 Application），别反复读：直接 phone_screenshot 看图，按位置 tap，一次批量做完再截下一张。
- 用 launch_app fresh=true 打开，回到首页。开屏可能有广告/弹窗：点「跳过」「点击收下」「不感兴趣」或左上角关闭。
- 首页：搜索框在顶部 y≈0.25（点它再输入，右侧「搜索」按钮 x≈0.9）。下方「附近商家」列表就是推荐店，可以直接点店名进店。底栏：首页 / 神券 / 订单 / 我的（y≈0.96）。
- 搜索：点搜索框 → type 关键词 → key return，等 2～3 秒出结果。搜索框里可能残留上次的词，用 type clear=true。
- 店铺页：左边分类、右边商品；商品右侧「+」或「选规格」加购，规格弹窗里选糖度/冰量/杯型后点「加入购物车」。
- 底部右下角「去结算」（约 0.85, 0.94），可能要点两次（先展开购物车再结算）。返回键在左上角（约 0.06, 0.09）。
- 结算页红包：配送费下面有一行「美团红包」，即使写着"购买神券包"也可以点进去看有没有免费可用的券；勾选后如果多出一笔费用（例如买神券包），先确认是否在用户同意的范围内，不确定就停下来问用户。
- 咖啡、奶茶也在美团外卖里点（搜品牌名，如「瑞幸」），不开品牌自己的 App。
- 购物车按店铺分开存，别家店里可能有旧商品，不要动。
- 付款步骤（提交订单、支付）是否可以直接点，以用户的规则为准；默认停在付款页、推送叫用户自己付。要刷脸或输密码时同样停在那一页叫用户。
