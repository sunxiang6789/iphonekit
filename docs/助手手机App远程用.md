# 用助手自己的手机 App 远程连电脑（补充用法）

这是助手**本身就有**的能力，不是本项目的主打。主打是 [侧边按钮 / 主屏幕快捷指令](../README.md)（系统级交互，延时最短）。

**使用这一用法的前提：你用的助手有官方手机控制端**（能在手机 App 里远程连电脑上正在跑的会话）。没有的话，这一页可以跳过，用快捷指令就够了。

思路：电脑上运行 Claude Code / Codex（装好了 iphone-use），你在手机上用它们官方的 App「远程连」这个会话，打字或说话下命令，电脑上的助手去操控 iPhone。

**这种方式本仓库不写代码，只需要：**
1. 跑完安装脚本（装好 iphone-use）。
2. 向导里同意把规则写进 `~/.claude/CLAUDE.md` / `~/.codex/AGENTS.md`（付款停在付款页由你自己付、任务结束交还手机等，都靠这份规则）。
3. 想收推送就配好 Bark（可选；你本来就在 App 里看着它回复）。

> ⚠️ 下面的信息是 2026-10 查到的，各家变得很快，**以官方文档为准**。标「待确认」的是我们没查实的，别当真。

## Claude Code：Remote Control

| 项目 | 情况 |
|---|---|
| 能不能用 | 能。官方功能叫 **Remote Control**，2026 年 2 月以「研究预览」推出 |
| 手机端 | Claude App（iOS / Android），或手机浏览器打开 claude.ai/code |
| 会话在哪跑 | 在你自己的电脑上，手机只是一个「窗口」，所以电脑上的 iphone-use 能用 |
| 哪些套餐能用 | 推出时先给 Max 用户，之后陆续开放 Pro——**你的套餐现在能不能用：待确认**，以官方说明为准 |
| 断线 | 会自动重连；断太久（报道说大约 10 分钟）会话会结束——待确认 |
| 怎么开 | 看官方文档 code.claude.com 的 Remote Control 页面（命令和入口可能随版本变） |

要注意：电脑要一直开着、不能睡眠；Claude Code 要在你装了 iphone-use 的那个用户下运行。

## Codex：ChatGPT App 远程控制

| 项目 | 情况 |
|---|---|
| 能不能用 | 能连 **Codex 桌面 App**：2026 年 5 月起 ChatGPT 手机 App（iPhone / iPad / Android）可以远程控制电脑上的 Codex，文件和权限都留在电脑上 |
| 只有命令行版（Codex CLI）行不行 | **待确认**。网上有第三方文章说 CLI 有实验性的远程控制命令，但说法互相矛盾、官方文档没查到，不建议依赖。只有命令行的话，请用快捷指令 |
| 工作区设置 | 有的团队/企业工作区默认关闭远程控制，需要管理员打开——待确认你的账号情况 |

## 其他助手

没测试过的助手（Cursor、Gemini CLI 等）是否有手机端远程连本地会话：**待确认**。只要它支持 MCP 并能远程连电脑上的会话，理论上都能接 iphone-use；欢迎实测后提 PR 补充这一页。

## 和快捷指令怎么搭配

| | 助手手机 App 远程连电脑 | 快捷指令（主推） |
|---|---|---|
| 前提 | 助手官方手机 App 支持远程连本地会话 | 只要装好本项目 |
| 下命令 | 在 App 里打字/说话，能看到过程 | 按侧边按钮或点主屏幕图标说一句话 |
| 拿结果 | 在 App 里直接看 | 自动推送（Bark） |
| 适合 | 想看着它干活、要来回聊 | 拿起手机说一句就走 |

两种可以同时用，互不影响。
