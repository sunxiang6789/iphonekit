# 常见问题自查

**先跑一遍体检**，大部分问题它会直接告诉你怎么修：

```bash
iphone-agent-kit doctor
```

下面按「现象 → 原因 → 怎么办」列出常见的坑。

---

### Xcode 明明装了，iphone-use 还是失败
- **原因**：Xcode 放在带空格的路径里（比如外接硬盘「My Disk/Xcode.app」）。iphone-use 检查进程时按空格切分路径，切错就失败。
- **怎么办**：运行 `iphone-agent-kit fix-xcode`，它会建一个不带空格的 `/Applications/Xcode.app` 替身，然后打印一条 `sudo xcode-select -s …` 命令，复制运行（要输 Mac 开机密码）。

### 设置/体检时报进程校验失败、时间对不上
- **原因**：终端里的时区和系统时区不一致，iphone-use 的进程校验会失败。
- **怎么办**：不要直接跑 `iphone-use setup`，用 `iphone-agent-kit iu setup`（会自动带上系统时区）。如果你在 `~/.zshrc` 里手动设过 `TZ`，删掉或改成和系统一样。

### 推送说「手机被别的会话占着」（phone_owned）
- **原因**：另一个助手会话（比如你在终端里直接开着的 Claude Code）正在用手机，iphone-use 一次只让一个人用。
- **怎么办**：等那边做完，或者在那边让它「交还手机」（`phone_release_owner`）。本工具**不会**强行抢手机，以免两边一起点乱套。

### 用了几天突然不能用了
- **原因**：免费 Apple ID 签的 iPhone 端程序 **7 天过期**。
- **怎么办**：手机连上 Mac，运行 `iphone-agent-kit resign`。`doctor` 会显示还剩几天；向导里开了「签名到期提醒」的话，剩 2 天会推送提醒你。付费开发者账号是一年。
- 如果 `doctor` 说不知道上次签名时间：刚签过的话运行 `iphone-agent-kit resign --mark-now` 记一下。

### 用 Claude Code 时任务马上失败，说没登录/没权限
- **原因**：后台服务调用的是命令行版 `claude`，需要单独登录；它也不读你 `settings.json` 里的 apiKeyHelper 之类设置。
- **怎么办**：终端里运行 `claude auth login` 登录，再 `iphone-agent-kit restart`。

### 向导说我没有「命令行版」，是什么意思
- **原因**：后台服务要在后台调用助手，靠的是命令行版（在「终端」里运行的 `claude` / `codex`），桌面版 App 本身不能被后台调用（虽然它里面自带了一份，通常能借用，但桌面版更新后路径会变）。
- **怎么办**：重跑 `iphone-agent-kit init`，向导问要不要帮你装时选「是」；或自己装：Claude Code 运行 `curl -fsSL https://claude.ai/install.sh | bash`，Codex 运行 `npm install -g @openai/codex`（或 `brew install codex`）。装完**新开一个终端窗口**再重跑向导。

### 「用 DeepSeek」没反应或报 MISSING_CREDENTIAL
- **原因**：没有可用的 DeepSeek API key。桌面版账号登录时自动生成的 key 命令行用不了。
- **怎么办**：去 platform.deepseek.com 新建一个 API key，在 DeepSeek Harness 桌面版的 Models 页面填好；然后重跑 `iphone-agent-kit init` 并选「配上 DeepSeek」（它会建专用配置并打开凭据读取）。

### 说完话快捷指令回了，但一直没收到推送
- **原因**：Bark 没配、key 填错，或 Bark 的通知被关了。
- **怎么办**：`doctor` 看「Bark」那项；重跑 `iphone-agent-kit init` 重新填 key（向导会发一条测试推送）；手机 设置 → 通知 → Bark 确认允许通知。还是没有的话看 `iphone-agent-kit logs`，里面有任务是否真的做完了。

### 快捷指令报错、连不上 Mac
- **原因**：下命令的手机和 Mac 不在同一个 Wi-Fi；Mac 睡眠了；后台服务没在跑；或者 Mac 的名字变了。
- **怎么办**：
  1. 手机和 Mac 连同一个 Wi-Fi。
  2. Mac 设置成不自动睡眠（系统设置 → 电池/能量 → 防止自动进入睡眠）。
  3. `iphone-agent-kit status` 看服务在不在，不在就 `iphone-agent-kit restart`。
  4. 改过 Mac 名字的话，重新 `iphone-agent-kit shortcuts` 并重新导入快捷指令。

### 被控的 iPhone 连不上 / doctor 说手机不可用
- **原因**：手机锁屏了、没信任这台电脑、开发者模式没开、或者数据线/无线连接断了。
- **怎么办**：解锁手机；确认 设置 → 隐私与安全性 → 开发者模式 已打开；第一次用先插数据线；按提示点「信任」。

### 人不在家时怎么用
- **办法**：用 [Tailscale](https://tailscale.com)（免费）。**只在 Mac 和你下命令的那台手机上装**，被控的 iPhone 不要装 VPN（会影响它和 Mac 的连接）。然后用 Tailscale 里 Mac 的名字或 100. 开头的地址重新生成快捷指令：
  ```bash
  iphone-agent-kit shortcuts --url http://<Mac 在 Tailscale 里的名字>:18800
  ```
- **做不到的情况**：人和被控手机**都**不在家（比如被控手机也带出门了）。被控手机要一直在 Mac 旁边、连着同一个网络。

### 推送说模型不可用 / model not found
- **原因**：默认配置里写了 Claude 的模型名（`claude-sonnet-5-5`、`claude-opus-5-5`、分流用的 haiku），你的账号可能没有其中某个。
- **怎么办**：编辑 `~/.config/iphone-agent-kit/config.json`，改 `routing` 里的 `model` 成你账号有的模型；或者直接关掉自动分流：
  ```json
  { "routing": { "enabled": false } }
  ```
  改完 `iphone-agent-kit restart`。

### 我想停下它
- 再运行一次快捷指令，说「停止」或「别弄了」。
- 你直接拿起被控手机开始用，AI 发现屏幕不是它在操作，也会停下来并推送告诉你。

### 卸载
- `iphone-agent-kit uninstall`：停掉后台服务、删命令、问你要不要删规则和配置。**不会卸载 iphone-use**，要卸 iphone-use 请看它自己的说明。
