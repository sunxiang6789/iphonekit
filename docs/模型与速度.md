# 模型与速度实测

> 测试环境：iPhone 17 Pro（iOS 27），Mac 与手机走 Wi-Fi 隧道，iphone-use 0.19.1，2026-10-21。
> 样本很少（每项 1～6 次），手机、网络、模型服务的波动都会影响结果，**看相对快慢，别当精确数字**。
> “热”＝上一个任务刚做完、手机还连着；“冷”＝上个任务已关 runner，要先重新接管手机（多约 12～20 秒）。

## ⭐ 一、命令行启动速度（重点看）

让助手“只回复两个字”，不点手机，量从启动到出结果的时间，每项跑 3 次。这是每个任务都要付的固定开销。

| 助手（命令行） | 模型 · 档位 | 带不带手机工具 | 3 次耗时（秒） | **中位数** |
|---|---|---|---|---|
| **dsh（DeepSeek Harness）** | DeepSeek flash · 档位 off | 不带 | 1.2 / 1.4 / 1.1 | **1.2 秒** ⭐ |
| **dsh** | DeepSeek flash · 默认档位 | 带 | 1.4 / 1.6 / 1.7 | **1.6 秒** ⭐ |
| **dsh** | DeepSeek v4-pro · 默认档位 | 带 | 3.4 / 1.5 / 1.7 | **1.7 秒** ⭐ |
| **dsh** | 水星 3 · 默认档位 | 带 | 2.4 / 2.2 / 2.4 | **2.4 秒** ⭐ |
| claude（Claude Code） | Haiku · 默认 | 不带 | 6.4 / 5.8 / 6.3 | 6.3 秒 |
| claude | Sonnet 5.5 · medium | 带 | 6.1 / 7.9 / 5.7 | 6.1 秒 |
| codex（Codex） | gpt-6.1-sol · low | 不带 | 10.3 / 8.4 / 7.3 | 8.4 秒 |
| codex | gpt-6.1-sol · low | 带 | 7.7 / 8.5 / 9.0 | 8.5 秒 |

**结论：dsh 的命令行启动最快（1～2.5 秒），Claude 约 6 秒，Codex 约 8.5 秒。** 同一个任务，光启动一项，dsh 就比另外两个少 4～7 秒。

## 四、没测或不可用的

| 项目 | 情况 |
|---|---|
| 水星 `mercury-decide` | 水星的接口不认这个名字（合法名字：mercury、mercury-2、mercury-2.5、mercury-3、mercury-3-preview-*、mercury-coder、mercury-coder-small、mercury-small） |
| 水星 3 + 档位 `off` | 不支持，会报错；用水星要把档位留空 |
| Claude Opus（“要动脑”任务用） | 没测手机任务耗时 |
| DeepSeek v4-pro 的手机任务耗时 | 只测了启动，没测手机任务 |
| 其他档位（Codex 的 medium/high、Sonnet 的 low/high、DeepSeek 的 low/high/max） | 没测，不知道对速度和准确度的影响 |

## 五、几点说明

- 档位越高通常越慢，但这里没有对比数据，别想当然。
- 同一个模型热、冷启动差异很大（水星 3：13 秒 vs 33 秒），所以“叫醒”功能（说话时预热手机）很值。
- 所有任务的答案都是对的（剩 200 多 G、天气晴 8～17 度）；这份表只比速度，没有比较更难任务的准确度。
