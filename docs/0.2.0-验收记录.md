# 0.2.0 验收记录

日期：2026-10-21。区分离线通过、实际 CLI 通过和真机待验证，不能把假手机的结果当成真机成功。

## 已通过

- Python 3.9（系统 Python）与当前 Python 的语法检查。
- 20 项离线测试：会话续接、保留原模型、明确新任务、多待办歧义、来源隔离、原生会话失效恢复、进度继承、三种询问推送、偏好同名替换、经验版本冲突、隐私字段省略、超长经验拒绝、普通问答不碰手机、其他会话/人工交还保护、锁屏不空等、迟到唤醒不重新启动 runner、stdio MCP 读写。
- 真实 dsh CLI + 假手机 MCP：自然报时不调用手机工具；可以读取真实时间工具。会话编号已保留。
- 真实 dsh 两轮对话：询问交付位置 → 同一个原生会话继续 → 用用户原话记录长期偏好。仅修改临时档案，没有写入真实偏好、备忘录或手机。
- 真实 Codex CLI + 假手机 MCP：已验证能调用新的时间工具并返回会话编号。自然报时可能直接回答，因此增加了每轮真实系统时间和时区的上下文。最终隔离测试中，dsh/Codex 均根据已附系统时钟回答，没有调用假手机工具；这证明有时间依据，不等于宣称它们又调用了一次时间工具。
- 真实后台复盘模型（dsh 专用 ack profile + 合成的操作事实）：返回了带证据引用的候选复盘；`verification` 保持 `not_verified`，未连接手机。
- 经验整份本地读取与内存快照测试：600 字符，300 次；本次机器中位约 0.025 毫秒，最大约 0.073 毫秒。仅代表本地读取，不含模型预填充、思考或网络延迟，也不是跨设备速度保证。
